# Degrees-of-Inmersion
This is a Degrees of Lewdity mod made to be used with modloader, it should work with most mods but just in case back-up your saves before using this.

This is a UI enhancing mod with multiple features, including a retractable sidebar, customible themes, a text offset slider, a toggleable location visual, compact statbars, and mobile support with the option to put the story below or above the sidebar.
